GUIDE 01

기능·파일 형식

일반 Markdown과 Starlit Markdown 읽기

SMDViewer는 읽기 전용 Markdown / Starlit Markdown 뷰어입니다. 제목·목록·표·링크·이미지·코드 블록을 표시하고, .smd 문서에서는 Starlit 글자색과 배경색도 해석합니다. 원본 편집은 VSCode 등 편집기에서 진행합니다.

형식표시 방식
.md일반 Markdown. 본문의 /r, $dr 같은 색상 기호를 그대로 표시
.smdMarkdown + Starlit 색상·문서 기본색·코드 강조. 색상 기호 대신 적용 결과 표시
제품 / 빌드 파일주요 용도환경
Windows · SMDViewer.exe문서 읽기, 검색, 확대·축소, 인쇄, A4 PDF·HTML 저장Windows 10/11 x64, .NET Framework 4.7.2 이상, WebView2 Runtime
VSCode · smd-preview-0.1.1.vsix.smd 편집 강조, 저장 전 실시간 미리보기, 원본 스크롤 동기화VSCode 1.85 이상. 별도 SMDViewer.exe·WebView2 설치 불필요
Android · SMDViewer-android-1.0.0.apk문서 열기·공유 수신, .md/.smd 미리보기, 두 손가락 확대Android 8.0 이상, 최신 Android System WebView 또는 Chrome

세 제품은 같은 렌더러를 공유합니다. 인쇄·PDF·HTML 저장은 Windows 앱의 기능이며 VSCode 확장과 Android 앱에는 포함되지 않습니다.

근거: readme.md, vscode-smd-preview/README.md·package.json, apk/readme.md.

GUIDE 02

Windows 뷰어

문서 열기부터 PDF·HTML로 보관하기까지

문서 열기

  1. 제공된 SMDViewer.exe를 원하는 위치에 복사합니다. PNG나 DLL을 함께 복사할 필요는 없습니다.
  2. 앱을 실행하고 열기 또는 Ctrl+O로 .md/.smd 문서를 선택합니다.
  3. 파일을 EXE 아이콘에 끌어 놓거나, 문서의 연결 프로그램을 SMDViewer.exe로 지정해 열 수도 있습니다.
  4. 문서를 수정한 뒤에는 새로고침, Ctrl+R 또는 F5로 다시 읽습니다. 앱 자체는 원본을 편집하지 않습니다.
기능버튼 / 단축키
문서 열기열기 / Ctrl+O
인쇄 미리보기·프린터 선택인쇄 / Ctrl+P
A4 PDFPDF 저장
단일 HTML 파일HTML 저장 / Ctrl+S
검색찾기 / Ctrl+F
다시 읽기새로고침 / Ctrl+R / F5
확대·축소+ / − / 100%
표시 모드다크 모드 / 브라이트 모드. 시작 시 기본 다크

PDF·HTML 저장

PDF는 A4와 배경색을 포함해 저장합니다. HTML은 스타일과 문서 폴더 안의 상대 경로 이미지를 포함한 단일 파일로 저장합니다. 원본의 배경색과 글자색을 유지합니다.

로컬 이미지는 문서와 같은 폴더 또는 하위 폴더에 둡니다. 외부 이미지는 서버 CORS 정책 때문에 HTML 내장이 거부될 수 있으며, 이 경우 앱이 오류를 표시합니다. 문서의 HTML 태그는 실행하지 않고 문자로 표시합니다.

실행 환경

.NET Framework와 Microsoft Edge WebView2 Runtime이 필요하며 EXE에 함께 포함되지는 않습니다. 일반 문서 읽기에는 관리자 권한이나 인터넷 연결이 필요하지 않습니다. 외부 이미지를 참조한 경우 해당 이미지를 읽을 때 네트워크를 사용합니다.

근거: readme.md와 src/ViewerForm.cs의 버튼·파일 열기·저장 구현.

GUIDE 03 · SMD PREVIEW 0.1.1

VSCode 미리보기

왼쪽에서 작성하고 오른쪽에서 바로 확인하기

  1. VSCode의 확장 → … → VSIX에서 설치(Install from VSIX...)에서 smd-preview-0.1.1.vsix를 선택합니다.
  2. .smd 파일을 열고 언어 모드가 Starlit Markdown인지 확인합니다.
  3. 편집기 우상단의 Open Preview to the Side를 누릅니다. 명령 팔레트의 SMD: Open Preview to the Side, 파일 탐색기의 .smd 우클릭 메뉴로도 열 수 있습니다.
  4. 왼쪽 내용을 편집하면 저장하기 전에도 오른쪽 미리보기에 반영됩니다.
조작사용법
오른쪽 미리보기Ctrl+K를 누른 다음 V 또는 Ctrl+Shift+V. macOS는 Cmd
새로고침SMD: Refresh Preview
기본 표시 모드smdPreview.theme: dark / bright. 미리보기 위쪽에서도 전환
미리보기 탭같은 문서는 기존 탭 재사용. 문서별로 각각 열기·저장된 문서 탭 복원 지원

0.1.1의 스크롤 동기화

원본 편집기를 위아래로 스크롤하면 해당 소스 줄에 맞춰 미리보기가 따라갑니다. 처음 열 때도 현재 위치에 맞추고, 숨겨지는 첫 줄 색상 설정과 긴 코드 블록 내부의 줄 위치도 반영합니다.

미리보기를 직접 스크롤해 따로 읽다가 원본을 다시 스크롤하면 동기화를 이어갑니다. 긴 본문은 블록 사이 위치를 보간하므로 글꼴과 자동 줄바꿈에 따라 약간의 차이는 생길 수 있습니다.

이미지와 링크

문서 폴더나 작업 영역 안의 상대 경로 이미지를 표시합니다. 작업 영역 밖 ../ 이미지는 허용된 리소스 범위 밖이면 표시하지 않습니다. 외부 HTTP(S) 이미지도 지원합니다. 웹 링크는 기본 브라우저로, 상대 경로 .smd/.md 링크는 편집기로 엽니다.

확장은 렌더러와 Starlit 문법 강조를 포함하므로 Starlitliter나 SMDViewer.exe를 따로 설치하지 않아도 됩니다. 인쇄·PDF·HTML 저장이 필요하면 Windows 뷰어를 사용하세요.

근거: vscode-smd-preview/README.md·CHANGELOG.md·package.json·extension.js.

GUIDE 04

SMD 작성 규칙

글자색·배경색과 Starlit 코드 강조

기호결과
/r · /#FF0000빨간 글자
$r · $#FF0000빨간 배경
/dr · $dr어두운 빨강 글자 / 배경
/R · $R연한 빨강 글자 / 배경
/d1기본 글자색 복원. 배경색 유지
$d1기본 배경색 복원. 글자색 유지
// · $$문자 / · $ 출력

색상 코드는 r o y l g t c s b v m p w k의 소문자·대문자이며 앞에 d를 붙일 수 있습니다. 56개 RGB 값은 Starlitliter의 기본 색상과 같습니다.

SMDViewer의 본문 색상은 복원 기호가 나올 때까지 유지됩니다. 줄바꿈만으로 색상을 해제하지 않습니다. 인라인 코드 내부 색상은 해당 영역 안에서만 유지됩니다. 링크 URL과 일반 코드 블록의 원문은 변경하지 않습니다.

문서 전체 기본색

.smd의 맨 첫 줄 전체를 색상 기호로 쓰면 문서 배경과 기본 글자색을 정합니다. 이 줄은 본문에 출력하지 않습니다.

$dK/w
# SMD 문서

진한 회색 배경과 흰색 기본 글자입니다.
/r빨강 /o주황 /#FF00FF자홍 /d1기본 글자색
$dr어두운 빨강 배경 $d1기본 배경

첫 줄에 문서 색상을 지정하면 그 값이 우선하며 다크·브라이트 모드 메뉴는 비활성화됩니다. 첫 줄 설정이 없거나 .md 문서이면 모드를 선택할 수 있습니다. 제목 아래 선과 표 테두리도 문서 색상에 맞춰 표시합니다.

인라인 코드와 코드 블록

인라인 코드가 `$dr빨강`처럼 배경 지정으로 시작하면 코드 요소의 여백까지 배경색을 적용합니다.

코드 울타리의 언어를 starlit으로 쓰면 Starlitliter의 기본 문법 강조를 적용합니다. starlit$dr/w처럼 울타리에 기본 배경·글자색을 더할 수도 있습니다.

```starlit$dr/w
main:
    OLED << "Hello, Starlit!" << OLED.ln
```

키워드·문자열·숫자·주석에는 문법 강조색이 우선합니다. 코드 문자열 안의 /r 같은 기호는 원문으로 남습니다. 개인 VSCode 강조 설정이나 외부 라이브러리 탐색까지 가져오는 방식은 아닙니다.

근거: readme.md·readme.smd의 SMD 규칙. 이 항목은 SMDViewer 규칙을 설명하며 사이트 게시판의 색상 처리와 구분합니다.

GUIDE 05 · ANDROID 1.0.0

Android

휴대전화에서 받은 .smd / .md 읽기

Android 8.0 이상과 최신 Android System WebView 또는 Chrome이 필요합니다. 제공 파일은 SMDViewer-android-1.0.0.apk이며, 로컬 설치용 개발 인증서로 서명한 APK로 Play 스토어 배포본은 아닙니다.

  1. 제공된 APK를 휴대전화에 설치합니다.
  2. 카카오톡이나 파일 앱에서 받은 .smd/.md 문서를 내려받습니다.
  3. 파일 열기에서 SMDViewer를 선택합니다. 직접 선택할 수 없다면 공유 / 다른 앱으로 열기를 사용합니다.
  4. 또는 SMDViewer의 파일 열기로 다운로드한 문서를 고릅니다.

.SMD/.MD처럼 대문자 확장자도 지원합니다. 파일명으로 형식을 판단하고, 파일명이 없으면 MIME 형식을 확인합니다. 구분할 수 없으면 SMD / Markdown 선택창을 표시합니다.

문서·이미지와 보관

  • 다크·브라이트 모드, 첫 줄 기본색, Starlit 강조와 두 손가락 확대·축소를 지원합니다.
  • UTF-8, UTF-8 BOM, UTF-16 BOM, CP949 한글 문서를 최대 16 MB까지 읽습니다.
  • 받은 파일의 읽기 권한으로 동작하며 원본을 변경하지 않습니다. 마지막 문서의 텍스트와 형식을 앱 내부에 보관해 다시 표시할 수 있습니다.
  • 카카오톡의 단일 파일 전달은 주변 이미지 파일의 권한을 주지 않으므로 이 버전은 상대 경로 이미지를 표시하지 않습니다. 문서에 넣은 data 이미지나 HTTPS 이미지를 사용합니다.
  • 문서 텍스트는 오프라인으로 볼 수 있습니다. HTTPS 이미지를 읽을 때는 네트워크를 사용합니다.

앱은 ACTION_VIEW와 ACTION_SEND 수신을 등록했습니다. 카카오톡 버전·파일 제공 방식에 따라 버튼 이름과 연결 과정은 달라질 수 있습니다.

근거: apk/readme.md. 해당 빌드 설명서에서는 APK 빌드·서명·파일 처리 검증은 완료했으나 실기기·카카오톡에서 실제 열기는 미확인으로 기록했습니다.
