LESSON 01 · LEVEL 1

Hello, World 출력

main에서 시작하는 첫 번째 출력

Starlit의 기본 스타일은 Pythonic입니다. 함수 이름 뒤에 콜론을 붙이고, 실행할 내용을 들여쓰기로 묶습니다. 원문의 시작 예제는 main: 안에서 OLED로 문자열을 출력합니다.

아래 출력·입력 예제는 OLED가 제공되는 보드 기준입니다. 원문에서 mini, HE, PR-VIT6, V는 OLED를 기본 제공하지만, CMD와 CMD Plus는 기본 제공 목록에 OLED가 없습니다. CMD의 LED Matrix 출력은 matrix 라이브러리가 필요하며, 상세 출력 API는 이 문서에 정의되어 있지 않습니다.

Hello, World! 출력

main:
    OLED << "Hello, World!" << OLED.ln

OLED <<는 값을 출력하고, OLED.ln은 줄을 바꿉니다. OLED에 Hello, World!를 출력한 뒤 다음 줄로 이동합니다.

입력과 출력 연결하기

main:
    value = int
    OLED << "값 입력 : " >> value << OLED.ln
    OLED << f"입력값 = {value}" << OLED.ln

>> value는 입력받은 값을 변수에 저장하는 원문의 표현입니다. value = int는 정수형 선언이며, 값을 초기화하는 문장이 아닙니다.

LESSON 02 · LEVEL 1

변수

초기값으로 자료형이 결정되는 정적 타입

변수는 이름 = 값으로 초기화합니다. 자료형만 선언하려면 이름 = 자료형으로 작성합니다. 한 번 정해진 자료형은 이후 대입으로 바뀌지 않습니다.

main:
    count = 0          # int
    voltage = 3.3      # float
    precise = 3.3D     # double, 대문자 D 사용
    pending = int     # 초기화 없는 선언
    count += 1
자료형크기 (byte)용도
int4부호 있는 정수
float4단일 정밀도 부동소수점
double8이중 정밀도 부동소수점
str256문자열
ref4메모리 주소
byte1단일 바이트 정수. LED Matrix·문자열 데이터 등에 사용

이름과 유효 범위

이름에는 알파벳, 숫자, 밑줄과 UTF-8 문자를 사용할 수 있지만 숫자나 _로 시작할 수 없습니다. 함수 밖의 전역변수는 코드 전체에서, 블록 안의 지역변수는 정의된 블록 안에서 유효합니다.

count = int
main:
    count = 10        # 전역변수에 대입
    if count > 0:
        count = int   # 같은 이름의 별도 지역변수 선언
        count = 3

하위 블록에서 같은 이름을 새로 만들려면 자료형 선언을 명시합니다. 레퍼런스 변수와 이름이 충돌하지 않도록 관련 규칙도 확인하세요. 소수 리터럴은 1.0k처럼 단위를 붙일 수 있으며, 원문 예제에서는 1000을 저장합니다.

근거: Starlit7_Syntax.md · 2.1, 2.2절. 예제는 원문의 문법을 바탕으로 학습용으로 정리했습니다.

LESSON 03 · LEVEL 1

조건문

if와 when으로 실행할 블록 선택하기

if / elif / else

if 조건:은 조건이 참인 경우 실행합니다. 앞의 조건이 거짓이면 다음 elif를 확인하고, 모두 거짓이면 인수 없는 else:를 실행합니다. 조건 인수 안에 변수 생성문을 넣을 수 없습니다.

main:
    value = -3
    if value > 0:
        OLED << "양수" << OLED.ln
    elif value < 0:
        OLED << "음수" << OLED.ln
    else:
        OLED << "0" << OLED.ln

이 예제에서는 음수를 출력합니다. 출력 부분은 OLED 보드 기준입니다.

when / case / default

when 값: 아래에 case를 배치합니다. 일치하는 항목이 없으면 default가 실행됩니다. 원문에 따라 case마다 break를 넣지 않습니다.

main:
    mode = 1
    result = 0
    when mode:
        case 0:
            result = 10
        case 1:
            result = 20
        default:
            result = -1

실행 후 result는 20입니다. when에는 반드시 case가 있어야 합니다.

근거: Starlit7_Syntax.md · 4.1, 4.2절. 예제는 원문의 문법을 바탕으로 학습용으로 정리했습니다.

LESSON 04 · LEVEL 1

반복문

조건 반복, 범위 반복과 반복 제어

while: 조건이 참인 동안 반복

main:
    count = 0
    while count < 3:
        OLED << f"{count}" << OLED.ln
        count += 1

OLED에 0, 1, 2를 한 줄씩 출력합니다. while 1:은 무한 반복입니다. break는 반복문을 빠져나가고, continue는 다음 조건 검사로 돌아갑니다.

표준형 for: 끝값을 포함하는 범위

for 변수:시작:증감:끝:으로 작성합니다. 증감이 1 또는 -1이면 생략할 수 있습니다. 원문의 1, 3, 5, 7, 9 출력 예제처럼 끝값을 포함합니다.

main:
    for i:1:2:9:
        OLED << f"{i}" << OLED.ln
    for j:0:2:
        OLED << f"{j}" << OLED.ln

첫 반복문은 1, 3, 5, 7, 9를, 두 번째는 0, 1, 2를 출력합니다. 이미 선언한 이름을 반복변수로 쓰면 별도 변수가 새로 생성되지 않습니다.

일반형 for와 반복문의 else

main:
    total = 0
    for(i = 0; i < 3; i++):
        total += i
    else:
        OLED << f"합계 = {total}" << OLED.ln

일반형은 for(초기화;조건;증감)을 사용합니다. 변수 생성은 초기화 구간에서만 가능합니다. 조건은 비울 수 없고, 무한 반복은 for(;1;)로 표현합니다. while과 for 뒤의 else는 break 없이 반복이 끝났을 때 실행됩니다. 위 합계는 3입니다.

원문 5.1의 첫 예제에 빠진 콜론을 보완하고, 5.2의 출력 변수 a는 반복변수 i로 고쳤습니다. while은 원문의 0~9 예제 동작에 맞춰 “조건이 참인 동안”으로 설명합니다.

LESSON 05 · LEVEL 1

함수

매개변수, 반환값과 참조 전달

형태정의 문법
매개변수·반환값 없음name: 또는 name():
매개변수 있음name(x:int):
반환값 있음name:int: 또는 name():int:
매개변수·반환값 있음name(x:int):int:

함수는 def 없이 이름으로 정의합니다. 매개변수와 반환 자료형을 명시하고, return으로 값을 반환합니다. 반환값은 하나만 허용됩니다.

add(a:int, b:int):int:
    return a + b

main:
    result = add(3, 4)
    OLED << f"합계 = {result}" << OLED.ln

OLED에 합계 = 7을 출력합니다.

참조로 전달하기

swap(a:_int, b:_int):
    temp = a
    a = b
    b = temp

main:
    a = 20
    b = 30
    swap(a, b)

_int 매개변수는 원래 변수에 접근합니다. 호출할 때는 swap(a, b)로 쓰고, 실행 후 a는 30, b는 20이 됩니다. 참조 반환은 반환형을 _int처럼 쓰고 주소를 반환합니다. 원문은 참조 반환 함수의 깊은 중첩이 컴파일 시간을 늘릴 수 있다고 설명합니다.

가변인수

$import studio를 추가하고 마지막 매개변수를 VA_LIST로 선언하면 가변인수를 받을 수 있습니다. 원문은 GetArgBytes(_a)와 sizeof(int)로 전달된 정수의 개수를 계산하는 예제를 제공합니다.

LESSON 06 · LEVEL 1

연산자

산술·비교·논리·비트 연산과 우선순위

아래 우선순위 숫자는 원문 기준이며 작을수록 먼저 계산합니다. 괄호로 계산 순서를 명확히 표현할 수 있습니다.

연산자우선순위의미 / 사용
. &nbsp; : &nbsp; []1멤버 접근 / 반복 / 배열 인덱스. 멤버 접근에 → 대신 점(.) 사용
- &nbsp; ! &nbsp; ~2음의 부호 / 논리 NOT / 비트 NOT. !는 not으로 대체 가능

^^3거듭제곱

+ -6덧셈 / 뺄셈
<< >> <<< >>>7정수 비트 시프트
< > <= >= == !=8비교. 세 항 이상의 비교는 별도 비교 연산으로 처리

main:

대부분의 이항 연산은 왼쪽에서 오른쪽으로, 단항·대입 연산은 오른쪽에서 왼쪽으로 처리합니다. 비교 연산에는 이 방향 규칙을 적용하지 않습니다. %, //, %%, 비트·논리 연산은 원문에서 정수형을 대상으로 합니다. OLED 출력의 <<는 출력 문맥의 표현입니다.

원문 표의 || 설명에는 “논리 and”라고 적혀 있지만, 같은 행의 $or와 대체어 or에 맞춰 여기서는 논리 OR로 정리했습니다. 음수의 몫·나머지와 확장 시프트의 세부 동작은 원문에 정의되어 있지 않아 별도 결과를 단정하지 않습니다.

LESSON 07 · LEVEL 1

기본 구조·주석·상수

들여쓰기, 주석 스타일과 변경할 수 없는 값

이 가이드는 기본값인 Pythonic 스타일을 사용합니다. 블록은 콜론과 들여쓰기로 나타내고, 예제의 들여쓰기는 4칸으로 통일했습니다. 한 줄 주석은 # 로 시작하며 # 뒤에 공백 한 칸이 필요합니다.

# 한 줄 주석
'''
여러 줄에 걸친 주석
'''
##CODE(1023)

main:
    OLED << f"코드 = {CODE:04d}" << OLED.ln

구간 주석은 ''' 또는 """로 시작하고 같은 기호로 닫습니다. Starlic·C/C++ 주석 스타일에서는 ///와 /** … **/를 허용하지만 Pythonic 주석과 한 파일 안에서 섞지 않습니다.

상수 두 가지

BOARD_CODE = 0x20처럼 초기화한 뒤 바꾸지 않는 관례로 상수를 사용할 수 있습니다. 변경 불가능한 상수는 ##CODE(1023)처럼 정의합니다. 지역 블록에서 정의한 매크로 상수는 그 블록 안에서만 유효합니다.

보드 타겟과 아이콘

원문은 코드 생성 시 기존 $target과 $icon의 파라미터를 수정하거나 임의로 추가하지 않도록 규정합니다. 예제를 기존 프로젝트에 적용할 때 설정된 타겟·아이콘 정보를 유지하세요.

LESSON 08 · LEVEL 1

문자열

일반 따옴표와 f-string의 자료형 차이

Starlit에서는 "Hello"와 f"Hello"의 자료형이 다릅니다. 일반 문자열 리터럴은 기본적으로 ref로, f-string은 str로 전달됩니다. 배열 초기화 안의 일반 문자열은 예외적으로 str 원소로 처리됩니다.

main:
    textRef = "Hello"       # ref
    text = f"Hello"         # str
    texts = ["Hello"]       # str 배열, 크기 1
    value = 20
    formatted = f"a = {value:03d}"
    OLED << formatted << OLED.ln

출력은 a = 020입니다. {value:03d}는 정수를 세 자리로 표시하고 남는 자리를 0으로 채웁니다. 원문은 Python f-string과 동일한 문법을 적용할 수 있다고 설명하지만, 중괄호 안에 문자열을 직접 넣는 것은 금지합니다.

근거: Starlit7_Syntax.md · 2.2–2.3절. 예제는 원문의 문법을 바탕으로 학습용으로 정리했습니다.

LESSON 09 · LEVEL 1

배열

고정 크기 배열과 여러 원소의 일괄 대입

이름 = 자료형[크기]로 선언하거나 값 목록으로 초기화합니다. 값 목록으로 만들면 첫 번째 값의 자료형과 원소 수로 배열이 결정되고, 나머지는 그 자료형으로 변환됩니다. 한 번 결정된 크기는 바꿀 수 없습니다.

main:
    values = int[20]
    values = [20, 30, 40]
    values[2] = [1, 2, 3]
    samples = [20, 30, 40]

위 코드의 values는 계속 20칸입니다. 마지막 대입 후 values[2], values[3], values[4]는 1, 2, 3이 됩니다. samples는 세 칸짜리 int 배열입니다. 선언만 한 배열의 나머지 원소가 초기화된다고 가정하지 마세요.

다차원 배열과 범위 대입

main:
    grid = int[8, 8]
    grid[0:7, 0:7] = 0
    grid[1, 1] = 5

차원과 인덱스는 쉼표로 구분합니다. grid[0:7, 0:7] = 0은 원문에 나온 전체 0 초기화 방식이며 끝 인덱스 7도 포함합니다. 그 뒤 (1, 1) 위치만 5로 바꿉니다. 이 표기는 Python의 끝값 제외 슬라이스와 혼동하지 않도록 주의하세요.

근거: Starlit7_Syntax.md · 2.5–2.6절. 예제는 원문의 문법을 바탕으로 학습용으로 정리했습니다.

LESSON 10 · LEVEL 1

레퍼런스

주소와 그 주소에 저장된 값을 구분하기

일반 변수 a의 주소는 _a로 나타냅니다. ref형과 별도로, 특정 자료형의 값에 접근하는 레퍼런스 변수는 b = _int처럼 선언합니다.

main:
    a = 20
    b = _int
    b_ = _a
    b = 1023

b_는 레퍼런스 변수에 저장된 주소이며, b는 그 주소의 값입니다. 따라서 마지막 줄은 a를 1023으로 바꿉니다. 값을 읽거나 쓰기 전에 참조할 주소를 연결해야 합니다.

1차원 배열 참조

main:
    values = [20, 30]
    items = _int
    items_ = _values
    items[1] = 1023

실행 후 values[1]은 1023입니다. 원문에서 이 배열 참조 사용법은 1차원에만 적용됩니다. 레퍼런스 변수 items를 선언했다면 주소 표기와 충돌하는 items_라는 일반 변수를 만들지 않습니다. 참조 전달 함수의 예제는 함수 메뉴에서 확인하세요.

LESSON 12 · LEVEL 1

파일 처리

call·open·make로 파일 읽고 쓰기

파일 기능과 주소 규칙은 플랫폼에 따라 다릅니다. 원문은 HE, ME, S-TerM을 설명하며 CMD의 파일 지원 여부는 정의하지 않습니다.
구문기능
call 주소:기존 파일을 불러와 읽기
open 주소:파일을 열고 끝에 이어 쓰기. 덮어쓰려면 첫 구문에 C_WRITE_OVR
make 주소:파일이 없을 때 새로 생성

CSV 정수 읽기

main:
    call "data.csv":
        data = toInt(0, 0)

toInt는 CSV의 특정 위치에서 정수를 읽습니다. 위 코드는 원문 예제로, S-TerM처럼 문자열 파일 경로를 허용하는 환경에서 사용합니다. call은 파일이 없을 때, make는 이미 존재할 때 else로 예외를 처리할 수 있습니다.

플랫폼주소 규칙
Starlit CMD/CMD Plus/R블록 주소(int)
S-TerM사용불가(파일 객체가 Starlit 플랫폼과 다릅니다.)
블록 안의 기능설명
read / write(data)1바이트 읽기 / 쓰기
read(data:ref, size:int) / write(data:ref, size:int)여러 바이트 읽기 / 쓰기
seek(pos) / tell()특정 위치로 이동 / 현재 위치 반환
toInt()CSV 정수 파싱
save파일 저장
close파일을 닫고 파일 처리 블록에서 빠져나가기

toFloat()는 원문에서 추가 예정으로 표시되어 있어 사용 가능한 기능으로 안내하지 않습니다.
