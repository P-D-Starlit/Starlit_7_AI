GitHub 계정으로 로그인하면 누구나 글과 댓글을 작성할 수 있습니다.

글쓰기 ↗ · GitHub 새 탭에서 열기 GitHub에서 전체 글 보기 ↗ · 새 탭

GitHub Issues와 연결된 공개 게시판입니다. 본문과 댓글은 이 페이지에서 읽을 수 있습니다. 글쓰기는 GitHub에서, 댓글 작성은 아래 GitHub 로그인 창에서 진행합니다.

/d1 또는 줄바꿈으로 원래 색상 복귀
글자색·배경색 작성 방법

/r빨강 /o주황 /#FF00FF자홍 /d1기본색처럼 작성합니다. 배경은 $r빨간 배경, $#FF00FF자홍 배경입니다.

/d1 또는 줄바꿈에서 글자색과 배경색이 모두 기본으로 돌아갑니다. $d1는 배경색만 해제합니다. //는 /, $$는 $로 표시합니다.

기본 색상: r 빨강 · o 주황 · y 노랑 · l 연두 · g 초록 · t 민트 · c 청록 · s 바다색 · b 파랑 · v 보라 · m 자홍 · p 장미 · w 흰색 · k 검정. 대문자는 연한 색상입니다.

본문·댓글의 일반 문장에 적용되며, Markdown 코드와 링크 주소는 그대로 유지합니다. 옵션을 끄면 원래 색상 코드가 보입니다. GitHub 원문과 로그인 작성창에서는 색상 코드가 텍스트로 보입니다.

    이렇게 참여하세요

    1. 제목을 선택하면 본문과 댓글이 위에 표시됩니다. 아래 목록에서 다른 글로 바로 이동할 수 있습니다.
    2. 새 글은 ‘글쓰기’에서 GitHub에 로그인한 후 작성합니다. 표·목록·코드·이미지는 Markdown으로 표시됩니다.
    3. 댓글은 ‘GitHub 로그인 · 댓글 쓰기’를 선택해 등록합니다. 알림과 글 관리는 GitHub에서도 확인할 수 있습니다.
