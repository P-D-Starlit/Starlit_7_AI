# SMD Viewer 예제

일반 Markdown의 **굵게**, *기울임*, 목록과 표를 함께 사용할 수 있습니다.

/r빨강 /o주황 /#FF00FF자홍 /d1기본 글자색

$dr어두운 빨강 배경 $d1기본 배경

인라인 코드: `$dr코드 영역 배경`

| 형식 | 표시 |
| --- | --- |
| .md | 색상 기호를 그대로 표시 |
| .smd | Starlit 색상 적용 |

```starlit$dr/w
main:
    OLED << "Hello, Starlit!" << OLED.ln
```

- `/d1`은 글자색만 복원합니다.
- `$d1`은 배경색만 복원합니다.
- `//`와 `$$`는 각각 `/`와 `$`입니다.
