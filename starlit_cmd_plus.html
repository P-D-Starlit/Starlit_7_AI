Starlit CMD Plus

7 × 7 LED Matrix로 넓어진 표현.

Starlit CMD Plus는 7 × 7 LED Display와 2개의 버튼을 갖춘 Starlit CMD 확장 보드입니다. ARM Cortex-M7 기반의 216 MHz 코어와 64 KB Code Unit으로 나만의 LED 패턴을 실행하세요.
