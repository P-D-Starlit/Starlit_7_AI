CMD LIBRARY GUIDE

Starlit CMD/CMD Plus 가이드

라이브러리를 선택하고 주요 함수와 실행 예제를 살펴보세요. 모든 Matrix 예제는 CMD의 5×7 크기를 기준으로 작성했습니다.

기준 문서: STARLIT_CMDPLUS/AI/Default.md · 버튼·함수 정의는 같은 보드 폴더의 헤더로 보완했습니다.
각 예제는 독립된 프로그램입니다. 하나씩 다운로드하거나 복사해 사용하세요.

예제 실행 준비
  1. CMD 또는 CMD Plus 보드를 PC에 연결하고 예제 .sl4 파일을 엽니다.
  2. StarStar의 F9 메뉴에서 실제 보드에 맞는 보드 설정과 COM 포트를 선택합니다.
  3. F5로 컴파일·업로드합니다. 기존 프로젝트에 복사할 때는 기존 $target·$icon 설정을 유지합니다.
  4. PuTTY 출력 예제는 보드와 같은 포트·속도의 터미널에서 확인합니다. 여러 터미널이 같은 포트를 동시에 열지 않도록 합니다.

코드들은 main과 필요한 import를 포함합니다. 라이브러리 내 SVM 내장함수 주소나 기본 초기화 코드는 수정하지 않습니다. 무한 반복 예제는 보드의 중지 기능 또는 재시작으로 종료합니다.

LIBRARY 01

Serial

PC 터미널로 메시지와 숫자 출력하기

Serial은 기본 제공 라이브러리입니다. UART2를 통해 USB 시리얼로 연결된 PC 터미널에 출력합니다. 이미 생성된 PuTTY 객체를 사용하므로 별도 import나 객체 생성은 필요 없습니다.

함수 / 표현사용법
PuTTY << 값문자열 또는 f-string을 PC 터미널에 출력
PuTTY.ln줄바꿈
PuTTY >> 변수시리얼 입력을 변수로 받기
PuTTY.Available()입력 데이터 도착 여부 확인
/r /g /b /y /w문자열 안의 글자 색상 코드. 서식 지원 터미널에서 적용
/0 또는 /[번호]출력할 터미널 행 지정. 반복 상태 표시에 사용

Hello, CMD!

기본 출력과 색상, 숫자 포매팅을 한 번에 확인합니다.

예제 다운로드 · .sl4 ↓
main:
    PuTTY << "Hello, CMD!" << PuTTY.ln
    PuTTY << "/rRED /gGREEN /bBLUE /wWHITE" << PuTTY.ln
    count = 7
    PuTTY << f"count = {count:02d}" << PuTTY.ln

실행 결과 · 터미널에 인사말, 색상 문자열, count = 07이 출력됩니다. 터미널이 서식을 지원하지 않으면 색상 코드가 그대로 보일 수 있습니다.

연결 속도는 사용하는 설치본의 설정과 일치시킵니다. 확인한 stuinit.shc의 PuTTY 객체 생성값은 460800 baud입니다. 원문 헤더 주석의 115200 표기와 다르므로 실제 설정값을 확인하세요.

근거: Default.md 1.2절. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 02

button

두 버튼으로 값을 바꾸고 동시 입력 처리하기

버튼 라이브러리는 기본 제공됩니다. 메인 반복문에서 InSwitch()를 계속 호출해 디바운싱된 입력 이벤트를 받습니다. 버튼을 계속 누르면 일정 간격으로 입력이 반복됩니다.

함수 / 표현사용법
InSwitch():int입력 없음은 0. 버튼 이벤트를 읽으며 LONG 플래그는 제거
SWITCH_1 / SWITCH_2각각 1번·2번 버튼
SWITCH_12두 버튼의 동시 입력. SWITCH_1 | SWITCH_2와 같은 값
BUTTON_Read():int길게 누름을 구분해야 할 때만 사용
SWITCH_1_LONG / SWITCH_2_LONGBUTTON_Read()의 길게 누름 이벤트 상수

버튼 카운터 0~99

1번 버튼은 감소, 2번 버튼은 증가하며 두 버튼 동시 입력은 종료합니다.

예제 다운로드 · .sl4 ↓
main:
    value = 0
    PuTTY << f"/0value = {value:02d}"
    while 1:
        sw = InSwitch()
        if sw == SWITCH_12:
            break
        elif sw == SWITCH_1:
            value -= 1
            value %%= 100
            PuTTY << f"/0value = {value:02d}"
        elif sw == SWITCH_2:
            value += 1
            value %%= 100
            PuTTY << f"/0value = {value:02d}"
    PuTTY << PuTTY.ln << "Counter stopped." << PuTTY.ln

실행 결과 · 터미널의 첫 행에 00~99 범위의 값이 표시됩니다. 감소·증가는 범위를 순환합니다.

Default.md 예제의 BUTTON_1/2는 호환용 상수입니다. 실제 button 헤더의 지침에 맞춰 새 예제는 SWITCH_1/2로 작성했습니다. InSwitch()로 LONG 플래그를 판별하지 마세요.

근거: Default.md 1.4절, button.shc. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 03

string

문자열 복사·연결·비교와 주소 전달

문자열 라이브러리는 기본 제공됩니다. C의 string.h 계열 함수에는 문자열의 레퍼런스를 전달합니다. 일반 따옴표 리터럴은 ref로 사용할 수 있고, 수정할 str 변수는 _변수명으로 전달합니다.

함수 / 표현사용법
strcpy(dst:ref, src:ref)문자열 복사
strncpy(dst:ref, src:ref, n:int)길이를 제한해 복사
strcat(dst:ref, src:ref)문자열 뒤에 연결
strncat(dst:ref, src:ref, n:int)길이를 제한해 연결
strcmp(a:ref, b:ref)같으면 0 반환
strncmp(a:ref, b:ref, n:int)앞 n개 문자 비교
strcmp2 / strncmp2대소문자를 구분하지 않고 비교

인사말을 만들고 비교하기

짧은 두 문자열을 str 변수에 복사·연결하고 결과를 비교합니다.

예제 다운로드 · .sl4 ↓
main:
    message = str
    strcpy(_message, "Hello, ")
    strcat(_message, "CMD!")
    PuTTY << message << PuTTY.ln
    if strcmp(_message, "Hello, CMD!") == 0:
        PuTTY << "MATCH" << PuTTY.ln
    PuTTY << _message + 7 << PuTTY.ln

실행 결과 · Hello, CMD!, MATCH, CMD!를 차례로 출력합니다. 마지막 줄은 앞의 7글자를 건너뛴 위치부터 읽습니다.

문자열을 복사하거나 연결할 때는 목적지 저장 공간을 넘지 않게 길이를 관리해야 합니다. 예제는 짧은 문자열만 사용합니다.

근거: Default.md 1.3절. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 04

studio

시간 측정과 내부 RGB LED 제어

시간 제어와 내부 LED 제어에는 $import(studio)를 추가합니다. Delay는 지정 시간 동안 실행을 멈추며, Tick은 밀리초 단위의 누적 시간을 읽습니다. 반복 작업은 main 안의 반복문으로 명시합니다.

함수 / 표현사용법
Delay(ms:int)ms밀리초 대기. 1000은 1초
Tick():int밀리초 누적 시간. 두 시점의 차이로 경과 시간 계산
LED_Write(pin:int, value:int)내부 LED 밝기. 이 가이드는 0~255 사용
핀 3 / 5 / 6CMD·CMD Plus 메인 LED의 빨강 / 초록 / 파랑
핀 9·8·4 / 0·1·2CMD Plus 전용 오른쪽 / 왼쪽 보조 RGB LED

내부 RGB LED를 순서대로 켜기

3·5·6번 채널만 사용하므로 CMD와 CMD Plus의 공통 기능으로 구성했습니다.

예제 다운로드 · .sl4 ↓
$import(studio)

main:
    while 1:
        LED_Write(3, 64)
        LED_Write(5, 0)
        LED_Write(6, 0)
        Delay(500)
        LED_Write(3, 0)
        LED_Write(5, 64)
        Delay(500)
        LED_Write(5, 0)
        LED_Write(6, 64)
        Delay(500)
        LED_Write(6, 0)

실행 결과 · 내부 RGB LED가 빨강·초록·파랑 순서로 0.5초마다 바뀝니다. LED Matrix 픽셀 출력과는 별개의 기능입니다.

Tick으로 1초 간격 카운트

기준 시각을 한 번 읽고 반복문에서 경과 시간을 검사합니다.

예제 다운로드 · .sl4 ↓
$import(studio)

main:
    count = 0
    last = Tick()
    while 1:
        if Tick() - last >= 1000:
            count += 1
            last += 1000
            PuTTY << f"count = {count}" << PuTTY.ln

실행 결과 · 시리얼 터미널에 약 1초 간격으로 count가 증가합니다. 길게 멈춘 경우에는 누락된 간격을 반복문에서 따라잡습니다.

근거: Default.md 2.1·2.3절, studio.shc. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 05

stulib

숫자 변환과 범위가 있는 난수

CMD 계열의 Default.md 기준으로 stulib은 기본 제공됩니다. 별도 import 없이 숫자 변환과 난수 함수를 사용할 수 있습니다. 문자열 객체를 직접 받는 변환 함수도 제공됩니다.

함수 / 표현사용법
atoi(text)문자열 → int
atoff(text) / atof(text)문자열 → float / double
labs(value:int)정수 절댓값
rand():int0~32767의 유사 난수
rand(start:int, end:int)시작값과 끝값을 모두 포함하는 범위 난수
rand2():int0~2^30-1의 난수
strtol(text, base [, pos])2~36진법 정수 변환. 선택 인수 pos는 수정 가능한 int 변수
itoa / utoa특수 진법 문자열 변환. 일반 출력은 f-string 우선

문자열을 숫자로 변환하기

10진수·실수·16진수 문자열을 변환하고 터미널에서 확인합니다.

예제 다운로드 · .sl4 ↓
main:
    decimal = atoi("123")
    real = atoff("3.25")
    hexValue = strtol("FF", 16)
    distance = labs(-7)
    PuTTY << f"decimal = {decimal}" << PuTTY.ln
    PuTTY << f"real = {real:.2f}" << PuTTY.ln
    PuTTY << f"hex = {hexValue}" << PuTTY.ln
    PuTTY << f"abs = {distance}" << PuTTY.ln

실행 결과 · decimal = 123, real = 3.25, hex = 255, abs = 7을 출력합니다.

주사위 값 10개 생성하기

rand(1, 6)은 양 끝을 포함하므로 별도 보정 없이 주사위 값으로 사용할 수 있습니다.

예제 다운로드 · .sl4 ↓
main:
    for i:1:10:
        dice = rand(1, 6)
        PuTTY << f"roll {i:02d}: {dice}" << PuTTY.ln

실행 결과 · 1~6의 정수를 10번 출력합니다. 난수라 실행할 때마다 결과가 달라질 수 있습니다. 원문에 따라 srand는 별도로 호출하지 않습니다.

근거: Default.md 3.1–3.6절. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 06

matrix

5×7 LED Matrix의 픽셀·영역·이미지 출력

반드시 $import(matrix)를 추가합니다. CMD는 가로 5·세로 7픽셀이므로 x=0~4, y=0~6을 사용합니다. 원점은 왼쪽 아래, x는 오른쪽, y는 위쪽입니다. CMD Plus에서도 아래 예제는 왼쪽 5열만 사용하며 나머지 열은 초기화 상태로 둡니다.

이미지 객체는 크기와 관계없이 img88입니다. 생성 직후 Clear()로 초기화하고, 데이터를 바꾼 후 PrintM()으로 실제 LED에 반영합니다.

함수 / 표현사용법
img = img88이미지 객체 생성. 곧바로 img.Clear() 호출
img.Clear()이미지 버퍼 전체를 0으로 초기화
img.Pixel(x, y, color)좌표 하나에 0xRRGGBB 색 지정
img.Color(xi, xe, yi, ye, color, 0)시작·끝 좌표를 모두 포함하는 영역 채우기. 마지막 인수는 0
img.data[c, y, x]채널 0=파랑, 1=초록, 2=빨강. 채널값은 0~255
img.PrintM()이미지 버퍼를 LED Matrix에 출력
img.Print2(text)최대 두 ASCII 문자 그리기. 이후 PrintM 필요. 로마자는 대문자 출력

색상 영역과 가운데 픽셀

5×7 전체를 어두운 파랑으로 채우고, 가운데 3×3 영역과 중앙 픽셀을 덧그립니다.

예제 다운로드 · .sl4 ↓
$import(matrix)

main:
    img = img88
    img.Clear()
    img.Color(0, 4, 0, 6, 0x000020, 0)
    img.Color(1, 3, 2, 4, 0x002000, 0)
    img.Pixel(2, 3, 0x200000)
    img.PrintM()

실행 결과 · 파란 바탕 위에 초록 3×3 영역이 생기고, 중앙 (2, 3)은 빨강이 됩니다.

채널 배열로 5×7 그라데이션

5개 열과 7개 행만 순회합니다. 최대 채널값은 180으로 255를 넘지 않습니다.

예제 다운로드 · .sl4 ↓
$import(matrix)

main:
    img = img88
    img.Clear()
    for x:0:4:
        for y:0:6:
            img.data[1, y, x] = x * 40
            img.data[2, y, x] = y * 30
    img.PrintM()

실행 결과 · 왼쪽 아래는 꺼지고, 오른쪽으로 갈수록 초록·위로 갈수록 빨강이 강해집니다. 오른쪽 위는 두 채널이 섞입니다.

35픽셀을 차례로 이동하는 점

프레임마다 지우고 새 점을 찍은 뒤 출력합니다. 한 번 순회하면 다시 왼쪽 아래에서 시작합니다.

예제 다운로드 · .sl4 ↓
$import(studio)
$import(matrix)

main:
    img = img88
    img.Clear()
    while 1:
        for y:0:6:
            for x:0:4:
                img.Clear()
                img.Pixel(x, y, 0x002020)
                img.PrintM()
                Delay(100)

실행 결과 · 청록색 점이 각 행의 왼쪽에서 오른쪽으로 이동하고 다음 행으로 올라갑니다. 35개 위치를 반복합니다.

Print2는 API 소개에 포함했지만 두 글자의 전체 표시 폭은 보드에 따라 달라집니다. 5×7 예제에서는 픽셀과 영역·배열 제어로 구성해 화면 밖의 열에 의존하지 않습니다. RGB 데이터 순서는 [c,y,x]이며 일반 색상 상수 0xRRGGBB와 구분하세요.

근거: Default.md 4.1–4.4절, matrix.shc. 예제는 CMD 5×7 화면과 공통 API에 맞춰 구성했습니다.

LIBRARY 07

math

실수 계산과 삼각함수 사용하기

$import(math)를 추가하면 C math.h 계열 함수를 사용할 수 있습니다. float 입력이면 float, double 입력이면 double을 반환하는 것이 기본이며 정수 반환 함수는 예외입니다. 이름에 f 접미사를 붙이지 않습니다.

함수 / 표현사용법
sqrt(x) / pow(x, y)제곱근 / 거듭제곱
sin(x) / cos(x) / tan(x)라디안 단위 삼각함수
rad(x) / deg(x)각도 → 라디안 / 라디안 → 각도
log(x) / log10(x) / exp(x)자연로그 / 상용로그 / 지수
floor(x) / ceil(x) / round(x)내림 / 올림 / 반올림
PI / EXP원주율 / 자연상수

제곱근과 거듭제곱

실수 리터럴을 전달하고 소수점 두 자리로 출력합니다.

예제 다운로드 · .sl4 ↓
$import(math)

main:
    root = sqrt(9.0)
    power = pow(2.0, 3.0)
    PuTTY << f"sqrt = {root:.2f}" << PuTTY.ln
    PuTTY << f"pow = {power:.2f}" << PuTTY.ln

실행 결과 · sqrt = 3.00, pow = 8.00을 출력합니다.

각도를 라디안으로 바꾸어 계산하기

degree를 float로 선언한 뒤 0·30·60·90도에 대한 sin 값을 계산합니다.

예제 다운로드 · .sl4 ↓
$import(math)

main:
    for angle:0:30:90:
        degree = 0.0
        degree = angle
        value = sin(rad(degree))
